## Coverage

34 entries across four categories:
- **C1 — Heritage artifact digitization** (8): photogrammetry, hybrid scanning, RTI, multispectral, neural pipelines.
- **C2 — Image-based reconstruction** (8): SfM-MVS reviews, MVS comparisons, NeRF / Gaussian Splatting vs photogrammetry.
- **C3 — Low-cost digitization** (9): smartphone photogrammetry, mobile LiDAR, low-cost reviews, cost/efficiency framing.
- **C4 — Virtual museums** (9): online/VR exhibitions, Web3D delivery, user studies.

Some papers appear in more than one category.

## What the literature establishes

- Artifact digitization with photogrammetry is mature.
- SfM-MVS is an established, relatively inexpensive workflow; acquisition strategy and overlap matter.
- Low-cost capture (consumer cameras, phones) is feasible.
- 3D artifacts can be delivered on the web and in virtual museums.

## Gap used by this project (Gap Matrix sheet)

Strongest candidate: one controlled, artifact-focused study linking **acquisition effort → compute effort → model quality → optimized museum asset**. Image-count vs quality and compute cost are rarely evaluated together for individual artifacts.
