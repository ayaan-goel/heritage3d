2. PROJECT IN ONE PARAGRAPH
============================================================

The project proposes a controlled and reproducible image-based 3D digitization framework for individual cultural heritage artifacts. The core research question is how image acquisition effort affects reconstructed geometric/visual quality and computational/storage cost. The same artifact will be reconstructed from different controlled subsets of available multi-view RGB images using a consistent COLMAP-based Structure-from-Motion (SfM) and Multi-View Stereo (MVS) pipeline. The outputs will be compared using suitable geometric-quality, completeness, runtime, resource-use and model-size measures. A selected reconstruction will then be optimized for web visualization and presented as an interactive artifact in a virtual-museum application.

The central principle:
Do not simply ask “Which reconstruction looks best?”
Ask “What reconstruction quality can be achieved at what image-acquisition and computational/storage cost?”

============================================================
3. PROBLEM, MOTIVATION AND SCOPE
============================================================

Motivation:
- Physical cultural heritage artifacts can deteriorate or be damaged.
- Physical access may be limited.
- Digital models can support preservation, documentation, research, education and virtual exhibitions.
- Image-based reconstruction is a practical route to create 3D models without requiring a dedicated active 3D scanner for every artifact.

Problem:
- Too few images or poor image coverage can lead to missing surfaces, incomplete geometry or weak reconstruction.
- More images can improve coverage and robustness, but also increase feature matching, processing time, storage and computational requirements.
- The project investigates the trade-off between image input, reconstruction quality and cost.

Project scope:
- Focus on individual heritage artifacts, not city-scale/urban asset reconstruction.
- Image-based 3D reconstruction.
- Controlled image-subset experiments.
- Geometric/visual quality and computational/storage cost evaluation.
- Model optimization for browser-based virtual museum presentation.

Out of scope unless later approved:
- Building a physical museum.
- City-wide urban asset management.
- Claiming continuous condition monitoring as a current implemented feature.
- Claiming that results exist before experiments have been run.
- Training YOLO or other neural networks unless a clear requirement is established; the current main reconstruction method is COLMAP/SfM + MVS, not necessarily a trained deep-learning model.

7. PROPOSED METHODOLOGY
============================================================

High-level pipeline:
CHSD
→ Multi-view RGB images
→ Controlled image subsets
→ COLMAP / SfM
→ Dense MVS
→ Point cloud
→ Mesh generation
→ Texture mapping
→ 3D artifact
→ Quality and cost evaluation
→ Model optimization
→ Web-ready model
→ Virtual museum

Detailed steps:

A. Dataset inspection and preparation
- Read official documentation and license.
- Inspect directory structure, image formats, depth-map formats and metadata.
- Choose one or more representative artifacts for a pilot.
- Record camera/view relationships if provided.
- Establish a repeatable train/experiment directory structure.

B. Controlled image subset generation
- Use the same artifact and consistent selection strategy.
- Proposed input levels discussed in the presentation: 100%, 50%, 25%, 12.5%, 6.25%.
- These percentages are planned experimental conditions, not results.
- Keep image selection reproducible and document the sampling procedure.
- Avoid confounding variables: keep reconstruction settings as consistent as possible across conditions.
- Consider whether subsets preserve adequate angular coverage rather than merely selecting consecutive or clustered views.

C. Sparse reconstruction using COLMAP/SfM
- Extract image features.
- Match features across overlapping views.
- Estimate camera parameters/poses and sparse 3D points.
- Check registration success, number of registered images and sparse point-cloud quality.

D. Dense reconstruction using MVS
- Use the calibrated images/cameras to estimate denser geometry.
- Export/inspect the dense point cloud.
- Document failures, missing surfaces and processing cost.

E. Mesh and texture
- Convert or process point cloud into a surface mesh using a suitable practical tool/workflow.
- Clean or simplify the mesh as needed.
- Generate texture maps from the images.
- Preserve an unoptimized/reference output as well as the optimized output so optimization does not obscure experimental comparisons.

F. Quantitative and practical evaluation
Potential geometric metrics, subject to compatibility with CHSD reference data:
- Chamfer Distance: average bidirectional point-set distance.
- Hausdorff Distance: worst-case/max geometric deviation.
- RMSE: root mean squared error for suitable corresponding measurements.
- Precision, recall and F-score at a declared distance threshold, where appropriate.
- Completeness/surface coverage, if measurable reliably.

Potential cost and model metrics:
- Number of input images.
- Total input image bytes.
- Feature extraction/matching/reconstruction time.
- Peak RAM/VRAM or other resource use where feasible.
- Number of registered images and reconstruction failure rate.
- Point count, mesh vertices and faces.
- Texture size and final model size.
- Browser loading/rendering behavior, if feasible.

Metric cautions:
- Define units, alignment procedure, sampling method and thresholds.
- Chamfer/Hausdorff/RMSE are not interchangeable; use only metrics that fit the available reference geometry.
- Reference depth maps may require camera calibration/projection to derive comparable geometry; validate the pipeline before claiming direct 3D ground-truth comparison.
- Do not report numerical results until actually measured.

G. Analysis
- Compare quality against image input and compute/storage cost.
- Plot the trade-off curves.
- Identify whether a lower-input condition retains acceptable quality for the intended use.
- Do not predetermine which image percentage will be “best”; this is the question being tested.

H. Web optimization and virtual museum
- Select a model based on measured quality–cost trade-off.
- Simplify mesh and compress/resize textures as appropriate.
- Export to a suitable web format such as GLB/glTF if compatible with the chosen viewer.
- Create a simple artifact-viewing page/interface with rotation/zoom and concise artifact information.
- Clearly label this as a prototype if it is not a production museum platform.

8. BASIC TECHNICAL TERMS
============================================================

Synthetic data:
Computer-generated or rendered data, rather than images captured directly from a physical scene.

RGB image:
A regular color image with red, green and blue channels.

Multi-view images:
Images of the same object from different viewpoints.

Camera pose:
The camera's position and orientation when an image was captured/rendered.

Point cloud:
A collection of 3D points representing sampled positions on an object's surface. Points may include color.

COLMAP:
An established open-source tool commonly used for image-based 3D reconstruction. It supports feature extraction/matching, camera pose estimation, sparse reconstruction and dense reconstruction workflows. Verify current license and dependencies before distribution.

SfM (Structure-from-Motion):
Estimates camera poses and sparse 3D structure from overlapping images.

MVS (Multi-View Stereo):
Uses multiple calibrated views to estimate denser 3D geometry.

Sparse point cloud:
A relatively small set of reconstructed 3D points, often created during SfM.

Dense point cloud:
A much denser collection of reconstructed surface points, often created during MVS.

Mesh:
A surface representation made from vertices, edges and polygon faces.

Texture mapping:
Applying image/color information to a 3D surface so it looks visually similar to the artifact.

Reference depth map:
An image in which pixel values encode distance/depth according to the dataset's convention. Check its encoding and coordinate conventions.

Quantitative geometry evaluation:
Numerically measuring how closely a reconstructed model matches reference geometry.

Chamfer Distance:
A bidirectional point-set distance measure often used to compare reconstructed and reference geometry.

Hausdorff Distance:
A measure of the largest nearest-neighbor deviation between two geometric sets.

RMSE:
Root mean square error, a measure of the magnitude of errors.

F-score:
A precision/recall-based measure, often calculated using a distance threshold for point-cloud comparison.

GLB/glTF:
A 3D asset format suited to sharing and rendering 3D scenes, including geometry and often textures/materials.

Virtual museum:
A digital interface in which users can inspect and interact with digitized artifacts.
